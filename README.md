# I AM NOMAD — сайт

Сайт туроператора I AM NOMAD: **https://www.iamnomadkg.com**

Сайт статический, сделан на [Astro](https://astro.build) и лежит на Vercel. Основной язык русский (`/`), английская версия — `/en/`. Страниц 31: главная, о нас, туры и страницы туров, I AM NOMAD SHOW, MICE, блог, отзывы, галерея, FAQ, контакты и 404.

---

## Для тех, кто ведёт сайт (без программирования)

### Админка: https://www.iamnomadkg.com/admin/

В админке меняются все тексты (RU и EN рядом), фото, туры, контакты, видео, страница SHOW и цены конструктора.

**Как войти.** Нужен аккаунт GitHub с доступом к репозиторию `pezzonovante09/IAmNomad`.

1. Создайте токен доступа на GitHub: **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
   - *Repository access*: Only select repositories → `IAmNomad`.
   - *Permissions → Repository permissions → Contents*: **Read and write**.
   - Срок действия выберите сами. Когда токен истечёт, создайте новый.
2. Откройте `/admin/`, нажмите **Sign In Using Access Token** и вставьте токен.

Браузер запоминает вход. Токен никому не передавайте: он даёт право менять сайт.

**Как публикуются правки.** Кнопка **Save** сразу сохраняет изменение в GitHub (ветка `main`). Через 1–2 минуты Vercel сам пересобирает сайт, и правка появляется на www.iamnomadkg.com. Все изменения сохраняются в истории GitHub, поэтому любую правку можно откатить.

**Что где в админке:**

| Раздел | Что там |
| --- | --- |
| **Тексты** → Общее | меню, кнопки, подвал, подписи форм |
| **Тексты** → SEO | заголовки вкладок и описания страниц для Google/Яндекса |
| **Тексты** → Главная, О нас, Туры, Тур: …, SHOW, MICE, Блог, Отзывы, Галерея, FAQ, Контакты | тексты соответствующих страниц |
| **Настройки** → Контакты и видео | телефон, WhatsApp, Telegram, почта, соцсети, ссылки на видео |
| **Настройки** → Фото | фото главной, «О нас», MICE, галерея, блог, аватары отзывов, Instagram |
| **Настройки** → Туры | статус (открыт / скоро / по запросу), обложка, галерея, число дней и пунктов |
| **Настройки** → I AM NOMAD SHOW | видео, постеры, фото блоков, цифры шоу, галерея, отзывы |
| **Настройки** → Конструктор | регионы, уровни комфорта и цены, «моменты» на фото, включение расчёта цены |

**Подсказки:**
- **Списки.** Строки, которые начинаются с `•`, выводятся на сайте пунктами списка. Каждый пункт пишите с новой строки.
- **Фото.** Нажмите на поле фото и загрузите файл: он сохранится в `public/uploads/`. Можно вставить и ссылку на картинку. Старые фото записаны как ID с Unsplash, их можно оставить.
- **Видео.** Для YouTube вставьте ссылку вида `https://www.youtube.com/embed/ID`. Если поле пустое, блок с видео не показывается.
- **Туры.** Список туров и их адреса меняет только разработчик. Число пунктов в «Настройки → Туры» показывает, сколько пунктов из текстов тура выводится на странице.

### Заявки с сайта

Каждая заявка из любой формы (заявка, контакты, корпоративная, SHOW, конструктор) уходит сразу в два места:

1. **Письмо на почту** через [Web3Forms](https://web3forms.com/), на адрес, к которому привязан ключ.
2. **База данных** [Supabase](https://supabase.com/): проект `iamnomad`, таблица `leads`.

Если одно из двух не сработало, заявка всё равно принимается. Ошибку посетитель видит, только когда не сработали оба.

**Где смотреть заявки.** Войдите на [supabase.com](https://supabase.com/dashboard), откройте проект **iamnomad** → **Table Editor** → **leads**. Новые заявки видно сразу, их можно фильтровать и сортировать.

| Колонка | Что это |
| --- | --- |
| `created_at` | когда пришла |
| `form` | откуда: `lead` — главная, `contact` — контакты и туры, `corporate` — MICE, `show` — I AM NOMAD SHOW |
| `name`, `email`, `phone`, `tour`, `message` | данные клиента |
| `data` | остальные поля: компания, даты, число гостей, WhatsApp, тип события |
| `page`, `lang` | страница и язык сайта |
| `status` | **меняйте сами**: `new` — новая, `in_progress` — в работе, `done` — закрыта, `cancelled` — отказ, `spam` — спам |
| `notes` | заметки менеджера |

**Безопасность.** Сайт использует публичный ключ, которому можно только добавлять заявки. Прочитать, изменить или удалить заявки через сайт нельзя: это закрыто правилами доступа (RLS). Смотреть заявки можно только в панели Supabase.

### Аналитика

Подключена [Vercel Web Analytics](https://vercel.com/docs/analytics): посещения, страницы, источники, страны, устройства. Она работает без cookie, поэтому баннер согласия не нужен. Смотреть её в панели Vercel: проект `i-am-nomad` → **Analytics**. Если аналитика ещё не включена, там же нажмите **Enable**.

## Для разработчиков

### Запуск

```bash
npm install
npm run dev         # локально: http://localhost:4321, админка — /admin/
npm run build       # сборка в dist/
npm run check       # проверка типов
npm run check:text  # после build: весь текст помещается на всех страницах (320–1920px)
```

Нужен Node.js 22.12+. Для `check:text` нужен Chromium для Playwright: `npx playwright install chromium`.

При локальном запуске в админке есть кнопка **Work with Local Repository**. Она правит файлы прямо на диске, без GitHub (работает в Chrome/Edge).

### Как устроено

```
src/
  content/            ← весь контент (его правит админка)
    texts/*.json      ← тексты по разделам: { "ru": {…}, "en": {…} }
    site.json         ← контакты, соцсети, видео
    photos.json       ← фото страниц, галерея, блог, аватары
    tours.json        ← структура туров
    show.json         ← медиа и цифры I AM NOMAD SHOW
    studio.json       ← конструктор: регионы, комфорт, цены, моменты
  components/LeadForm.astro ← все формы: отправка в Web3Forms + Supabase
  data/*.ts           ← типизированные обёртки над content/*.json
  i18n/utils.ts       ← загрузка текстов, t(key), localize()
  views/*.astro       ← страницы (маршруты — src/pages/[...path].astro)
  components/*.astro  ← шапка, подвал, логотип, формы, конструктор и т.д.
  styles/global.css   ← цвета, шрифты, сетка, кнопки
public/
  admin/index.html    ← страница админки (Sveltia CMS)
  uploads/            ← файлы, загруженные через админку
scripts/
  cms-config.mjs      ← генерирует public/admin/config.yml и копирует редактор
  check-text-fit.mjs  ← проверка, что текст помещается
```

**Тексты.** Ключи в коде записаны с точками (`t('home.hero.line1')`). В JSON точки заменены на `__` (`home__hero__line1`), потому что в админке точка в имени поля означает вложенность. Если ключа нет в текущем языке, берётся русский вариант, а если нет и его — сам ключ.

**Новый текст.** Добавьте ключ в нужный `src/content/texts/<раздел>.json` сразу для `ru` и `en`. Поле в админке появится само: `scripts/cms-config.mjs` строит список полей из JSON перед каждым `dev` и `build`. Новый раздел добавьте в словарь `sections` в том же скрипте, чтобы у него было понятное название.

**Админка** — [Sveltia CMS](https://github.com/sveltia/sveltia-cms), совместима с Decap CMS. Редактор ставится из npm (`@sveltia/cms`) и при сборке копируется в `public/admin/`, внешний CDN не нужен. `config.yml` и копия редактора генерируются, в git их нет.

**Логотип** собран из текста и CSS (`src/components/Logo.astro`): «I AM» — `#E4AE25`, «NOMAD» — `#07703F`, «O» — кольцо с золотой точкой. Иконки сайта (`public/favicon.svg`, PNG) используют этот же знак.

### Переменные окружения

Задаются в настройках Vercel, см. `.env.example`:

- `PUBLIC_WEB3FORMS_KEY` — ключ Web3Forms (без него используется ключ по умолчанию из `src/data/site.ts`);
- `PUBLIC_SUPABASE_URL`, `PUBLIC_SUPABASE_KEY` — проект Supabase и его публичный ключ для записи заявок (по умолчанию проект `iamnomad`, см. `src/data/site.ts`);
- `SITE_URL` — адрес сайта для canonical, hreflang, sitemap и превью в соцсетях (по умолчанию `https://www.iamnomadkg.com`).

### Публикация

Каждый push в `main` Vercel сам собирает и публикует на www.iamnomadkg.com; iamnomadkg.com перенаправляет на www. Для других веток Vercel делает preview-сборки. Старые адреса (`tour-classic.html` и т.п.) перенаправляются на новые через `vercel.json` (и `public/_redirects` для Netlify).

### База заявок (Supabase)

Таблица `public.leads` в проекте `iamnomad` (регион eu-central-1). Роли `anon`/`authenticated` могут только вставлять строки и только в колонки `form, name, email, phone, tour, message, data, page, lang`. Колонки `status` и `notes` сайт заполнить не может. Длины полей ограничены проверками в таблице. Форма шлёт `POST /rest/v1/leads` с заголовком `Prefer: return=minimal`, поэтому ответ не содержит данных.

### SEO

- `sitemap-index.xml` с RU/EN версиями (`@astrojs/sitemap`), `robots.txt` (`/admin/` закрыт);
- canonical, hreflang и Open Graph на каждой странице;
- страница 404 и админка закрыты от индексации.
